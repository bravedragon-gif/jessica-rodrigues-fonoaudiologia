07 / Interaction patterns

THE specials.

Os quatro comportamentos que tornam a experiência reconhecível: parede fotográfica, sticky stack, parallax e comportamento sensível à rolagem.

Photo Wall / 170% × −14°

A demonstração desloca as linhas em sentidos alternados com base no scroll e na posição horizontal do mouse. O CSS original aumenta a largura da plane para 220% ou 260% nos breakpoints menores.

.wall { overflow:hidden; mask-image:linear-gradient(90deg,transparent,#000 13%,#000 87%,transparent); }
.plane { position:absolute; left:-35%; top:-45%; width:170%; height:190%;
  transform:rotate(-14deg); display:flex; flex-direction:column; gap:14px; }
.wall-row { display:flex; gap:14px; will-change:transform; }
/* No JS, cada linha tem direção alternada e deriva por scroll + mouseX. */

09 / Developer handoff

BUILD notes.

Orientações técnicas fundamentadas no HTML de referência. Os exemplos são pequenos recortes; para a versão completa, consulte o arquivo index.html.

Stack

HTML sem framework, Tailwind via CDN (cdn.tailwindcss.com), CSS complementar e JavaScript vanilla.

Fonts

Google Fonts: Archivo variável no eixo width/weight, Bodoni Moda variável no eixo optical size e Inter 400–700.

Render loop

Uma função frame() centralizada com requestAnimationFrame e função enter(rect, vh, span) para progresso normalizado.

Media policy

Usar vídeos com muted loop playsinline preload="metadata"; observer com limiar .25 controla play/pause.
